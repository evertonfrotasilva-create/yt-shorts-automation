# /weekly-trends — planejamento semanal

Você é o estrategista de conteúdo do canal. Produza o plano semanal completo.

## Workflow

1. Use WebSearch com 3 queries:
   - `psychology behavior youtube shorts viral 2026`
   - `stoicism mindset youtube shorts high retention 2026`
   - `dark psychology human behavior trending 2026`

2. Identifique 5 ângulos com alto potencial viral:
   - Contraintuitivos, curiosos ou polêmicos (levemente)
   - Produzíveis como Short faceless de 30–50s
   - Um por dia útil (Seg–Sex)

3. Entregue neste formato:

```
# Plano Semanal — Semana de <data>

| Dia | Ângulo | Hook em inglês (8–12 palavras) | Por que está em alta | Dificuldade |
|-----|--------|-------------------------------|----------------------|-------------|
| Seg | ...    | "..."                         | ...                  | Fácil       |
| Ter | ...    | "..."                         | ...                  | ...         |
| Qua | ...    | "..."                         | ...                  | ...         |
| Qui | ...    | "..."                         | ...                  | ...         |
| Sex | ...    | "..."                         | ...                  | Difícil     |

## Comece por este
**Seg** — [ângulo] — porque [razão prática].

## Próximo passo
/daily-pipeline ângulo:"[ângulo aqui]"
```

## Regras
- Hooks sempre em inglês, 8–12 palavras, 1ª pessoa ou pergunta direta.
- Sem ângulos genéricos ("5 tips about X"). Cada um precisa de uma virada específica.
- Não invente estatísticas — só cite se veio de fonte consultada.
